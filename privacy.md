# Privacy Policy

## isCandid / Website Trust Analyzer

Effective date: April 16, 2026

`Website Trust Analyzer` analyzes the website currently open in the browser tab and sends the tab URL to the project backend so the service can calculate a trust score and return a recommendation.

## Data the extension processes

The extension may process:

- The URL of the active tab when the user opens the extension popup.
- Basic page signals detected in the current tab, such as whether return-policy, delivery, or ecommerce keywords appear on the page.
- The analysis response returned by the backend service.

## How data is used

This data is used only to:

- Analyze the currently viewed website.
- Generate a trust score, risk level, and purchase recommendation.
- Display the analysis result inside the extension popup.

## Data sharing

The extension sends the active tab URL and detected page signals to the project backend:

- `https://trustbackend-one.vercel.app/analyze/`

The extension does not sell user data.

## Data storage

The extension itself does not intentionally store personal data in the browser. Any server-side logging, retention, or analytics should be disclosed by the backend operator if enabled.

## User control

Users control when analysis happens by opening the extension on a page. If a user does not want a page analyzed, they should avoid opening the extension on that page and may remove the extension at any time.
